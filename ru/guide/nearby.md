# Nearby LAN-синхронизация

**OpenKey Pro** может синхронизировать один сейф между устройствами в локальной Wi‑Fi **без self-hosted сервера**. Шифротекст передаётся по спаренной LAN-сессии; ключ сейфа делится только после явного нажатия **Связать сейф**.

На этой странице: спаривание, QR-коды, связь сейфа, отправка записи, LAN Pro и правила доверия. Краткое устранение неполадок: [FAQ](./faq#nearby-не-находит-другое-устройство-pro). Модель угроз: [Безопасность](./security#модель-угроз).

## Требования

- OpenKey Pro на каждом устройстве, которое должно синхронизироваться (или действительная аттестация **LAN Pro** на платформах без магазинного IAP — см. ниже)
- Оба устройства разблокированы и в **одной LAN** (не гостевой Wi‑Fi / изоляция клиентов)
- **Настройки → Устройства рядом** запущены с обеих сторон

Nearby — **не** резервная копия. Держите также Pro [зашифрованный `.okbak`](./import-export#зашифрованное-резервное-копирование-pro).

## Спарить устройства

1. Разблокируйте OpenKey на обоих устройствах → **Настройки → Устройства рядом**.
2. Включите **Видимость в локальной сети** (запоминается: возобновляется при следующей разблокировке, пока сейф разблокирован).
3. Спарьтесь одним из способов:
   - **QR (предпочтительно):** рекламирующее устройство показывает QR для спаривания; на другом нажмите **Сканировать QR спаривания** (или **Вставить QR спаривания** на Linux/Windows) — код вводить не нужно.
   - **Короткий код:** введите код, показанный на пире, в течение примерно двух минут.
4. После спаривания нажмите **Связать сейф**, чтобы оба разделяли один отпечаток ключа сейфа. Одно спаривание никогда не делится ключом сейфа автоматически.

Если ключи сейфа различаются, принимающее устройство может **принять** ключ пира (заменяет локальные данные сейфа после подтверждения мастер-пароля). Относитесь к связи + принятию как к полному доверию сейфу.

### Файрвол / обратное подключение

Некоторые десктопы (особенно macOS) блокируют входящий TCP. Если сканирование QR не подключается, OpenKey может попросить хост QR перезвонить гостю (только unicast UDP — код спаривания не транслируется в LAN). Разрешайте запросы локальной сети / файрвола, когда ОС спрашивает. Предпочитайте одну подсеть; VPN и private relay часто ломают обнаружение. Слишком много неверных кодов вызывает краткую блокировку.

## После связи

- Изменения синхронизируются автоматически, пока оба сейфа разблокированы и Nearby рекламируется.
- Используйте **Синхронизировать сейчас** для ручного обновления.
- Синхронизация — **last-write-wins по revision** (то же правило, что у [сервера](./server)) — по возможности редактируйте на одном устройстве за раз.
- **Доверенные устройства:** после успешного спаривания + связи сейфа пиры переподключаются и синхронизируются, когда Nearby включён — без повторного спаривания.
- **Только доверенные сети (опционально):** добавьте SSID дома/офиса; Nearby приостанавливается, если текущий SSID не в списке (и блокирует запуск, если список пуст). Когда ОС не может прочитать SSID, Nearby может работать с предупреждающим баннером.
- **Отвязать** отзывает LAN-доверие, останавливает синхронизацию и очищает LAN Pro claims этого пира.

## Отправить запись

Можно отправить один логин спаренному пиру без ожидания полной синхронизации сейфа:

1. Откройте запись (или используйте действия пира Nearby в **Настройки → Устройства рядом**).
2. Выберите **Отправить на устройство** / отправить запись этому пиру.
3. Пир получает шифротекст по LAN-сессии и может сохранить локально.

Используйте для разовых обменов в LAN; предпочитайте [организации и шаринг](./sharing), когда пиры используют один self-hosted сервер.

## Аттестация LAN Pro

На платформах **без** покупки в магазине (обычно Windows / Linux) Pro-пир со связанным сейфом может передать статус **LAN Pro**, чтобы другое устройство сняло лимиты Pro через Nearby. Одного спаривания недостаточно — сначала нажмите **Связать сейф**.

- Только удобство — **не** криптодоказательство покупки.
- Android, iOS и macOS (магазинный IAP) **игнорируют** LAN Pro; купите или восстановите Pro в том магазине.
- Отвязка останавливает аттестацию.

## Сводка доверия

| Действие | Смысл доверия |
|--------|-------------------|
| Спарить | Ключ сессии с этим пиром в LAN |
| Связать сейф | Поделиться материалом ключа сейфа — пир может синхронизировать полный шифротекст сейфа |
| Отправить запись | Пир получает шифротекст этой записи |
| LAN Pro | Пир может снять лимиты Pro на платформах без IAP |

Спаривайте и связывайте только с устройствами и людьми, которым доверяете. Подробнее: [Безопасность → Модель угроз](./security#модель-угроз).
