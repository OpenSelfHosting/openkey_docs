# Использование приложения

OpenKey — клиент для мобильных и настольных платформ: Android, iOS, macOS, Linux и Windows. Основные функции сейфа бесплатны; OpenKey Pro открывает дополнительные возможности. Сейф хранится зашифрованным на устройстве; self-hosted [сервер](./server) для синхронизации необязателен. Приложение устанавливайте его из официального магазина или канала загрузки вашей платформы.

## Установка

1. Получите OpenKey в официальном магазине / у дистрибьютора вашей платформы.
2. Откройте приложение и создайте или разблокируйте сейф мастер-паролем.

Open-source пакеты этого проекта охватывают только [сервер](./server), [расширение браузера](./extension) и [CLI](./cli).



## Бесплатно и OpenKey Pro {#free-vs-openkey-pro}

Базовые функции сейфа работают офлайн без подписки. На Android, iOS, macOS, Windows и Linux Pro повышает лимиты и открывает доп. возможности. Web-сборки пока не требуют Pro. На платформах **без** магазинного IAP (обычно Windows/Linux) Nearby-пара может передать аттестацию **LAN Pro** — удобство, не криптодоказательство покупки.

| | Бесплатно | Pro |
|--|------|-----|
| Записи входа | До **50** | Без лимита |
| Коллекции (папки) | До **3** | Без лимита |
| Карты / крипто / секреты | До **3** каждого | Без лимита |
| Sync сервера, автозаполнение, импорт | Да | Да |
| **Экспорт**, бэкап **`.okbak`**, **Nearby**, **орги/шаринг**, **вложения**, **иконка** | — | Да |

Подписка: **Настройки → OpenKey Pro**, где доступна оплата магазина.

## Nearby LAN-синхронизация (Pro)

Синхронизируйте один сейф по локальному Wi‑Fi без сервера:

1. Разблокируйте OpenKey на обоих устройствах → **Настройки → Устройства рядом**.
2. Запустите Nearby на обоих, спарьте коротким кодом, затем **Связать сейф**.
3. Нужен общий ключ сейфа (один отпечаток). Если ключи разные, получатель может принять ключ пира (заменит локальные данные после подтверждения мастер-пароля).
4. После связи изменения синхронизируются, пока оба разблокированы; **Синхронизировать сейчас** — вручную.
5. **Видимость в локальной сети** запоминается: после включения Nearby возобновляется при следующей разблокировке.
6. Опция **Только доверенные сети**: добавьте SSID; на чужих сетях Nearby паузится.
7. **Доверенные устройства**: после пары + связи переподключаются сами при включённом Nearby.

LAN sync передаёт только **шифротекст** (LWW по revision). Это не бэкап. См. [FAQ](./faq) · [Шаринг](./sharing) · [Импорт и экспорт](./import-export).

## Создание или разблокировка сейфа

1. Выберите надёжный **мастер-пароль** (рекомендуется 12+ символов разных типов).
2. Примите предупреждения сейфа: **восстановления нет**, если забудете мастер-пароль; данные зашифрованы на устройстве; резервные копии важны.
3. Разблокируйте мастер-паролем при каждом открытии приложения.

Мастер-пароль никогда не покидает устройство в открытом виде.

## Повседневное использование

### Главная сейфа

- Просматривайте **коллекции** (папки) и **записи** паролей.
- Ищите, фильтруйте по тегам и открывайте запись, чтобы скопировать логин/пароль или посмотреть пользовательские поля.
- Создавайте записи с URL, заметками, иконками и TOTP, где поддерживается.

### Генератор паролей

Откройте **Настройки → Генератор паролей** (или генератор из формы записи), чтобы создавать надёжные пароли с вашей длиной и правилами символов.

### Карты, крипто и секреты

Зарезервированные области сейфа содержат:

- **Платёжные карты**
- **Криптокошельки**
- **Секреты разработчика** (API-токены, SSH-ключи, фрагменты `.env`) — также используются [CLI](./cli)

### Организации и общий доступ

Делитесь коллекциями или отдельными элементами с другими пользователями OpenKey на том же сервере. Имена org и payload общего доступа остаются зашифрованным текстом на сервере.

## Карта настроек

| Раздел | Назначение |
|------|----------------|
| **Внешний вид** | Тема и язык (те же локали, что на этом сайте документации) |
| **Безопасность** | Блокировка / биометрия / связанные защиты |
| **Генератор паролей** | Параметры генерации по умолчанию |
| **Данные** | Sync сервера, импорт/экспорт, резервные копии, расширение браузера, общий доступ |
| **OpenKey Pro** | Управление подпиской, где доступно |

## Подключение self-hosted сервера

1. Запустите [OpenKey Server](./server).
2. **Настройки → Данные → Self-hosted server** → укажите URL → **Register** или **Login** → **Sync now**.

Подробнее: [Установка сервера](./server).

## Автозаполнение и браузер

- **Autofill mobile / desktop:** включите OpenKey как системного провайдера паролей и passkeys в Настройки → Безопасность.
- **Браузер:** установите расширение; на desktop разблокируйте приложение и зарегистрируйте native host, или разблокируйте расширение против сервера в standalone-режиме.

## Импорт, экспорт и резервное копирование

- **Import / export:** переносите пароли (Bitwarden JSON, Chrome CSV, 1Password CSV, OpenKey JSON). Экспорт расшифровывает на устройстве — относитесь к файлу как к конфиденциальному.
- **Local backup / restore:** зашифрованные резервные копии устройства (Pro где требуется).
- Предпочитайте offline-резервные копии даже при sync сервера — забытый мастер-пароль нельзя восстановить с сервера.

## Хорошие привычки

- Используйте уникальный надёжный мастер-пароль.
- Синхронизируйте после крупных изменений при использовании сервера.
- Храните хотя бы одну offline-резервную копию.
- Блокируйте сейф, уходя от общего компьютера.
