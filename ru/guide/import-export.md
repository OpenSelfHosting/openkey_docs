# Импорт и экспорт

Переносите пароли между OpenKey и другими менеджерами или делайте зашифрованный полный бэкап сейфа. Путь: **Настройки → Данные → Импорт и экспорт** (и **Резервное копирование и восстановление** для `.okbak`).

| Действие | Бесплатно | Pro |
|--------|------|-----|
| Импорт (все форматы ниже) | Да | Да |
| Экспорт (все форматы ниже) | — | Да |
| Зашифрованный локальный бэкап / восстановление (`.okbak`) | — | Да |

Экспорт и бэкапы расшифровываются на устройстве перед записью файла — относитесь к каждому экспорту как к **секрету**. Предпочитайте офлайн зашифрованное хранение. См. [FAQ](./faq) и [Бесплатно и OpenKey Pro](./app#бесплатно-и-openkey-pro).

## Пошаговый импорт

1. Разблокируйте OpenKey.
2. **Настройки → Данные → Импорт и экспорт → Импорт**.
3. Выберите формат, укажите файл, подтвердите.
4. Проверьте новые записи/коллекции в сейфе. Синхронизируйте с [сервером](./server), если используете его.

### Bitwarden JSON

1. В Bitwarden: экспорт **JSON** (незашифрованный экспорт — защитите файл).
2. В OpenKey: Импорт → **Bitwarden JSON**.
3. Папки мапятся в коллекции где возможно; логины становятся записями.

### Chrome / Edge CSV

1. Менеджер паролей браузера → экспорт CSV.
2. OpenKey → Импорт → **Chrome CSV**.
3. Ожидайте колонки url / username / password; пользовательские поля могут быть ограничены.

### LastPass CSV

1. LastPass → экспорт CSV.
2. OpenKey → Импорт → **LastPass CSV**.

### 1Password CSV

1. 1Password → экспорт CSV (формат, поддерживаемый импортёром OpenKey).
2. OpenKey → Импорт → **1Password CSV**.
3. Сложные типы элементов могут свернуться в записи, похожие на логин.

### KeePass (`.kdbx`)

1. OpenKey → Импорт → **KeePass `.kdbx`**.
2. Введите пароль базы и опциональный **файл ключа**.
3. Группы становятся коллекциями; записи импортируются как логины, когда поля мапятся чисто.

Неверный пароль / файл ключа → разблокировка не удалась; без обращения к серверу (всё локально).

### OpenKey JSON

Формат round-trip для нативных экспортов OpenKey. Используйте при переносе между устройствами без sync сервера или как портативный дамп сейфа (**Pro** для создания файла).

**Вложения:** экспорты OpenKey JSON включают *метаданные* вложений в записях, но **опускают blobs шифротекста вложений**. Для полного сейфа с вложениями используйте зашифрованный **`.okbak`**.

## Пошаговый экспорт (Pro)

1. **Настройки → Данные → Импорт и экспорт → Экспорт**.
2. Выберите формат. Для KeePass задайте новый пароль базы (и опциональный файл ключа).
3. Сохраните файл в зашифрованное / офлайн место.
4. Удалите plaintext-экспорты после завершения миграции.

Доступные экспорты: **OpenKey JSON**, **Bitwarden JSON**, **Chrome CSV**, **LastPass CSV**, **KeePass `.kdbx`**, **1Password CSV**.

## Зашифрованное резервное копирование (Pro)

**Настройки → Данные → Резервное копирование и восстановление**

- Создаёт полный `.okbak` сейфа (база, настройки, вложения), зашифрованный для восстановления вашими учётными данными сейфа.
- Восстановление заменяет локальные данные сейфа — подтвердите перед продолжением.
- Nearby / sync сервера — **не** бэкап ([FAQ](./faq)).

## После миграции с другого менеджера

1. Проверьте важные логины (и TOTP, если использовали).
2. Включите [автозаполнение](./app) / [расширение](./extension).
3. Синхронизируйте с сервером или спарьте Nearby (Pro) для других устройств.
4. Безопасно удалите старые файлы экспорта.
5. По желанию смените пароли, которые были в незашифрованном CSV при переносе.
