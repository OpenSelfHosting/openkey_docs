# OpenKey Pro — что открывается (и что нет)

Основное хранилище OpenKey работает офлайн без подписки. **Pro** снимает лимиты и открывает функции, важные при синхронизации между устройствами, экспорте или совместной работе в команде. Практическое разделение — и оговорка про LAN Pro, которая часто сбивает с толку.

## Что остаётся бесплатным

- Локальное зашифрованное хранилище (с лимитами freemium — см. ниже)
- Self-hosted [синхронизация через сервер](/ru/guide/server) (только шифротекст)
- Системное автозаполнение / passkeys там, где это разрешает ОС
- Мост [расширения браузера](/ru/guide/extension) к разблокированному десктопному приложению
- **Импорт** из Bitwarden, CSV браузера, KeePass и других источников

Лимиты бесплатного уровня (сборки mobile/desktop с проверкой Pro): **50** записей логинов; **3** коллекции, платёжные карты, криптокошельки и секреты разработчика каждого типа.

## Что открывает Pro

| Возможность | Примечания |
|-------------|------------|
| Неограниченные записи / коллекции / карты / крипто / секреты | Снимает лимиты Free |
| **Экспорт** + зашифрованный бэкап **`.okbak`** | Относитесь к экспорту как к секрету |
| Синхронизация хранилища **Nearby** по LAN | QR-пара, связка хранилищ, отправка записи — [руководство](/ru/guide/nearby) |
| Организации и общий доступ | Тот же self-hosted сервер |
| Вложения к записям | ~20 МБ каждое, шифротекст на сервере |
| Пользовательская иконка приложения | Там, где платформа это поддерживает |

Полная матрица: [Цены](/ru/pricing) · [Использование приложения → Free и Pro](/ru/guide/app#free-vs-openkey-pro).

## LAN Pro — это не чек из магазина

На платформах **без** покупок в магазине приложений (обычно Windows / Linux) узел Pro может передать **LAN Pro**-аттестацию по Nearby, чтобы другое устройство получило лимиты Pro в LAN.

- Только для удобства — **не** криптографическое доказательство покупки
- Android, iOS и macOS **игнорируют** LAN Pro; купите или восстановите Pro в соответствующем магазине
- Отмена сопряжения прекращает аттестацию

## Веб-сборки

**В веб-сборках Pro пока не проверяется.** В мобильных и десктопных сборках из магазина и для десктопа — проверяется. Учитывайте это при тестировании в браузере.
