# Nearby без сервера

Self-hosted API синхронизации мощен — и опционален. **Nearby** (OpenKey Pro) сохраняет ту же модель с нулевым разглашением в локальной сети: устройства обнаруживают друг друга, спариваются для ключа сессии, и вы либо **копируете сейф** на новое устройство при настройке, либо явно нажимаете **Связать сейф** для постоянной merge-синхронизации. Одно сопряжение никогда автоматически не делится ключом хранилища.

## Когда это использовать

- Два или больше ваших устройств в одной домашней или офисной Wi‑Fi
- Нужна синхронизация без поднятия Docker / Postgres
- **Новый телефон или десктоп** должен получить полную копию сейфа без файла `.okbak`
- Нужна разовая **Send to device** для одного логина без полной выгрузки хранилища

Merge-синхронизация — **не** бэкап. Храните офлайн зашифрованный [`.okbak`](/ru/guide/import-export) (Pro). Гостевые сети и изоляция клиентов ломают обнаружение — используйте обычный сегмент LAN.

## Скопировать сейф на новое устройство

1. Разблокируйте существующее устройство → **Настройки → Устройства рядом** → **Видимость в локальной сети**.
2. На новом устройстве выберите **Устройство рядом** в селекторе первого запуска.
3. Нажмите на пира → подтвердите → разблокируйте **тем же мастер-паролем**.

Так передаётся полный архив сейфа, зашифрованный сессией (включая вложения). Подробности: [Nearby → Скопировать сейф при настройке](/ru/guide/nearby#скопировать-сейф-при-настройке-клонирование-сейфа).

## Спарить для постоянной синхронизации

1. Разблокируйте OpenKey на обоих устройствах → **Настройки → Устройства рядом**.
2. Включите **Видимость в локальной сети**.
3. Нажмите на обнаруженного пира для спаривания (короткий код всё ещё работает примерно в течение двух минут, когда обнаружение неудобно).
4. Нажмите **Связать сейф**, чтобы оба устройства разделяли один отпечаток ключа хранилища.

Если файрвол Mac блокирует входящий TCP, OpenKey может попросить рекламирующий хост перезвонить — разрешите сетевые запросы ОС.

## После связки

Изменения синхронизируются, пока оба хранилища разблокированы и Nearby рекламируется (**побеждает последняя запись по revision**, то же правило, что и на сервере). Доверенные устройства переподключаются автоматически; опция **Только доверенные сети** приостанавливает Nearby вне ваших SSID. **Отменить сопряжение** отзывает доверие LAN и заявки LAN Pro.

## LAN Pro, кратко

На Windows / Linux (без покупок в магазине) **связанный** узел Pro может передать **LAN Pro**-аттестацию, чтобы другое устройство получило лимиты Pro. Сопряжение без связки недостаточно. Android, iOS и macOS это игнорируют — купите или восстановите Pro в магазине. Относитесь к аттестации как к удобству, а не к криптографическому доказательству покупки.
