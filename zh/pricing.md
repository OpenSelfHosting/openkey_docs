# 定价

**OpenKey** 免费提供完整加密保险库，并设有合理上限。**OpenKey Pro** 取消上限，并解锁导出、备份、Nearby、共享和附件。

商店价格在 Apple / Google / Microsoft 各区域计费中设定，并在应用内购买时显示。本页说明**您能获得什么**以及**如何购买**——并非固定的美元价目表（商店会本地化货币和税费）。

相关：[使用应用](/zh/guide/app#free-vs-openkey-pro) · [OpenKey Pro 说明](/zh/blog/openkey-pro) · [下载](/zh/guide/download) · [服务条款](/zh/terms)

## 计划

| 计划 | 计费 | 说明 |
|------|---------|--------|
| **免费** | $0 | 核心保险库 + 服务器同步 + 自动填充 + 导入（有条目上限） |
| **每月** | 订阅 | 自动续订；可随时在商店中取消 |
| **每年** | 订阅 | 自动续订；通常续订性价比最高；可随时取消 |
| **终身** | 一次性 | 为该商店账户永久解锁 Pro |

具体金额见 Android、iOS 和 macOS 上的 **设置 → OpenKey Pro**（及其他列出的 IAP 平台）。

## 免费与 Pro {#free-vs-openkey-pro}

| | 免费 | Pro |
|--|------|-----|
| 登录条目 | 最多 **50** | 不限 |
| 集合（文件夹） | 最多 **3** | 不限 |
| 支付卡 | 最多 **3** | 不限 |
| 加密钱包 | 最多 **3** | 不限 |
| 开发者密钥 | 最多 **3** | 不限 |
| 自托管服务器同步 | 是 | 是 |
| 自动填充 / 通行密钥（系统） | 是 | 是 |
| 浏览器扩展桥接 | 是 | 是 |
| 从其他管理器导入 | 是 | 是 |
| **导出** | — | 是 |
| **加密 `.okbak` 备份** | — | 是 |
| **Nearby 局域网保险库同步** | — | 是 |
| **组织与共享** | — | 是 |
| **附件**（每项约 20 MB） | — | 是 |
| **自定义应用图标** | — | 是 |

免费与 Pro 的零知识原则相同：服务器仍只能看到密文。Pro 解锁的是客户端功能与限额——并非 OpenSelfHosting 托管的「云保险库」。

## 如何订阅

1. 从支持应用内购买的[下载渠道](/zh/guide/download)安装 OpenKey（Play 商店、App Store、Mac App Store 等，以实际列出为准）。
2. 解锁保险库 → **设置 → OpenKey Pro**。
3. 选择 **每月**、**每年** 或 **终身**，并完成商店购买。
4. 若在同一商店账户下重装或更换设备，请使用 **恢复购买** / 刷新状态。

### Windows 与 Linux

应用内购买适用于 **Android、iOS 和 macOS**。在 Windows 和 Linux 上：

- 在支持账户关联 Pro 时，于手机或 Mac 上订阅后，使用**同一 OpenKey 账户**登录，**或**
- 从已配对的 Nearby Pro 对等方使用 **LAN Pro**（仅为便利——不是商店收据；Android / iOS / macOS 会忽略 LAN Pro）

详情：[Nearby → LAN Pro](/zh/guide/nearby#lan-pro-attestation) · [常见问题](/zh/guide/faq)

### Web 构建

Web 构建**尚未强制 Pro**。移动版和桌面商店版会强制。

## 管理或取消

- **Apple：** 设置 → Apple ID → 订阅（或 App Store 订阅）
- **Google Play：** Play 商店 → 付款和订阅
- **Microsoft：** account.microsoft.com / 商店订阅（如适用）

退款遵循商店政策。见[服务条款](/zh/terms)。

## 常见问题

### 免费版不付费能用吗？

可以——保险库、自动填充、导入和自托管同步在上述上限内可用。

### 自托管服务器需要 Pro 吗？

不需要。免费版即可服务器同步。Pro 增加导出、备份、Nearby、组织/共享、附件及更高限额。

### 价格会变吗？

商店可能调整区域价格。应用内付费墙始终显示您账户和所在区域的当前方案。
