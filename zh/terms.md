本服务条款（「条款」）规范您对 **OpenKey** 应用及 OpenSelfHosting 发布的相关官方软件包的使用。下载、安装或使用 OpenKey，即表示您同意本条款。

相关：[隐私政策](/zh/privacy) · [安全](/zh/guide/security)

## 1. 服务

OpenKey 是在您的设备上加密保险库数据的密码管理器。可选的同步 API 在您将应用指向您控制（或由他人为您运营）的服务器时，仅存储**密文**。OpenSelfHosting 不提供文档中所述免费核心体验的一部分的强制性托管保险库云。

开放软件包（服务器、扩展、CLI、文档）通常按其仓库中发布的 **MIT 许可证**提供。移动/桌面应用除本条款外，还可能受商店条款约束。

## 2. 资格

您须能在您的司法管辖区订立有约束力的合同，并满足安装 OpenKey 的应用商店账户的最低年龄要求（至少 13 岁，或当地要求更高）。

## 3. 您的账户与主密码

- 您使用**主密码**创建并控制保险库。
- **无法恢复主密码。** 若您忘记主密码，且没有可解锁的设备会话或可打开的加密备份，您的密文按设计不可恢复。
- 您有责任选择强主密码、保留所需备份，并在保险库解锁期间保护设备安全。

## 4. 可接受使用

您同意不：

- 使用 OpenKey 违反法律或他人权利
- 试图破坏 OpenSelfHosting 基础设施、其他用户的保险库或您无权测试的系统（按我们的[安全政策](/zh/guide/security#reporting-vulnerabilities)报告的私人安全研究除外）
- 虚假陈述 Pro 购买状态或滥用商店退款/证明机制
- 违反 Apple、Google 或 Microsoft 协议重新分发专有商店构建

您运行的自托管服务器须由您自行保护（HTTPS、密钥、访问控制）。配置错误由您负责。

## 5. OpenKey Pro 与购买

部分功能需要 **OpenKey Pro**（例如超出免费上限的无限条目、导出、加密 `.okbak` 备份、Nearby 局域网同步、组织/共享、附件）。见[使用应用](/zh/guide/app#free-vs-openkey-pro)。

- 商店购买与订阅由平台（Apple / Google / Microsoft）计费。适用其退款与取消规则。
- 在某些桌面平台上通过 Nearby 共享的 **LAN Pro** 是对等方证明便利，不能替代 IAP 平台上的商店购买。
- 价格与功能可用性可能变更；我们将在文档或商店列表中反映重大产品变更。


## 6. 第三方服务

OpenKey 可能与以下服务交互：

- 操作系统自动填充 / 通行密钥 API
- 您的自托管同步服务器
- 应用商店计费 API
- 您配对的 Nearby 对等方

这些服务有各自的条款。我们不对第三方中断或政策负责。
