# 概览

OpenKey 是一款 **自托管、端到端加密的密码管理器**。客户端在数据离开设备前加密保险库内容。可选的同步服务器仅存储 **密文** — 主密码和明文保险库密钥绝不会离开客户端。

## 您将获得

- 本地加密保险库（集合、登录项、卡片、加密钱包、开发者密钥）
- 通过您自己的服务器在设备间可选同步
- 带自动填充和 passkeys 的浏览器扩展
- 移动 / 桌面应用和开发者 CLI
- 组织、共享集合与条目共享 — 在服务器上仍为密文

## 零知识模型

1. 客户端使用 **Argon2id** 从主密码派生密钥。
2. `auth_hash` 在不暴露主密码的情况下向服务器认证。
3. 保险库内容使用服务器永远看不到明文的保险库密钥加密。
4. 名称、载荷、附件、组织名称和共享载荷在服务器上以不透明密文存储。

| `openkey_cli` | 开发者 CLI（密钥、密码生成、同步） |
