# Nearby 局域网同步

**OpenKey Pro** 可在本地 Wi‑Fi 上跨设备同步同一保险库，**无需自托管服务器**。密文经已配对的局域网会话传输；仅在你明确 **链接保险库** 后才会共享保险库密钥。在**新设备**上，也可在首次运行时通过 Nearby **复制**已有保险库（保险库克隆）— 仍是点对点，不会经过同步 API。

本页涵盖发现、点按配对、设置时克隆保险库、链接保险库、发送条目、LAN Pro 与信任规则。排查：[常见问题](./faq#nearby-找不到另一台设备-pro)。威胁模型：[安全](./security)。协议细节：[OpenKey 规范 → Nearby](https://github.com/OpenSelfHosting/OpenKey/blob/main/spec/nearby.md)。

## 要求

- 需要同步或克隆的每台设备都有 OpenKey Pro（或在无商店 IAP 平台上有效的 **LAN Pro** 证明 — 见下文）
- 同一 **局域网**（非访客 Wi‑Fi / 客户端隔离）
- **合并同步**：两台设备均已解锁，且已打开 **设置 → 附近设备**
- **设置时保险库克隆**：已有设备已解锁并在广播，且显示有保险库；新设备走首次运行的 **附近设备** 路径

Nearby 合并同步 **不是**备份。请同时保留 Pro 的[加密 `.okbak`](./import-export#加密备份-pro)。保险库克隆会一次性复制整个保险库（含附件）；之后仍请保留离线备份。

发现信标在局域网上以**明文设备名**广播（以及表示对端是否已有账户的 `vault` 标志）。只接受你自己的设备。锁定保险库会暂停 Nearby，直到再次解锁。

Linux 与 Windows 可能提示一次开放局域网端口（**UDP/TCP 47821**、**TCP 47822**）。请允许这些提示，以便对端能找到本机。

## 设置时复制保险库（保险库克隆）

当你有一台**新手机或电脑**，希望通过 Wi‑Fi 收到已有保险库的完整副本时使用（无需 `.okbak` 文件，也无需服务器）。

1. 在**已有**设备上：解锁 OpenKey → **设置 → 附近设备** → 打开 **在本地网络可见**。对端须显示**已有保险库**。
2. 在**新**设备上：首次运行选择器 → **附近设备**（或等效设置路径）。
3. 点按发现的对端 → 确认复制。持有保险库的一方推送（或空设备拉取）经会话加密的归档，经局域网传输。
4. 在新设备上用与源相同的**同一主密码**解锁。密码不会在线路上发送 — 仅解锁材料与保险库密文在已配对会话内传输。

克隆包含本地数据库、偏好、附件、可选头像，以及账户解锁字段（邮箱、盐、KDF、封装的保险库密钥）。若该邮箱已在新设备上存在，克隆会以 `email_exists` 失败。

**克隆 vs 链接保险库**

| | 保险库克隆 | 链接保险库 |
|--|-------------|------------|
| 时机 | 首次运行 / 空设备 | 两台设备都已有保险库 |
| 结果 | 将一整份保险库复制到空设备 | 共享保险库密钥指纹；持续 LWW 合并同步 |
| 主密码 | 用同一密码解锁副本 | 两边均已解锁 |

## 配对设备（合并同步）

1. 两台设备解锁 OpenKey → **设置 → 附近设备**。
2. 打开 **在本地网络可见**（会记住：保险库解锁后下次自动恢复）。
3. 点按发现的对端以配对（短配对码经局域网会话自动交换）。发现不便时，约两分钟内手动输入短码仍然可用。
4. 配对后点 **链接保险库**，使双方共享同一保险库密钥指纹。仅配对不会自动共享保险库密钥。

若密钥不同，接收端可 **采用** 对端密钥（在确认主密码后替换本地保险库数据）。请将链接 + 采用视为完整保险库信任。

### 防火墙 / 回拨

部分桌面系统（尤其 macOS）会阻止入站 TCP。Linux 与 Windows 构建可能提示一次开放 **UDP/TCP 47821** 与 **TCP 47822**。若对端无法拨入，OpenKey 可让广播主机回拨访客（仅单播 UDP — 配对码不会在局域网广播）。请允许系统的局域网 / 防火墙提示。尽量同一子网；VPN 与专用中继常会破坏发现。错误代码过多会触发短暂锁定。

## 链接之后

- 双方保险库解锁且 Nearby 在广播时，变更会自动同步。
- 用 **立即同步** 手动追赶。
- 同步为按 revision 的 **最后写入获胜**（与[服务器](./server)相同）— 尽量一次只在一台设备上编辑。
- **受信任设备：** 一次成功配对 + 链接后，只要 Nearby 开启即可自动重连同步 — 无需重新配对。
- **仅受信任网络（可选）：** 添加家庭/办公室 Wi‑Fi SSID；当前 SSID 不在列表时 Nearby 暂停（列表为空则阻止启动）。当系统无法读取 SSID 时，Nearby 仍可能运行并显示警告横幅。
- **取消配对** 可撤销局域网信任、停止同步，并清除该对端的 LAN Pro 声明。

## 发送条目

可在不等待完整保险库同步的情况下，向已配对对端推送单个登录项：

1. 打开条目（或在 **设置 → 附近设备** 使用对端操作）。
2. 选择 **发送到设备** / 向该对端发送条目。
3. 对端通过局域网会话收到密文并可本地保存。

适合局域网上的一次性分享；若对端使用同一自托管服务器，更推荐[组织与共享](./sharing)。

## LAN Pro 证明 {#lan-pro-attestation}

在 **没有** 商店内购的平台（通常是 Windows / Linux）上，**已链接保险库** 的 Pro 对端可共享 **LAN Pro** 状态，使另一台设备通过 Nearby 解锁 Pro 限额。仅配对不够 — 必须先点 **链接保险库**。

- 仅作便利 — **不是**购买的密码学证明。
- Android、iOS、macOS（商店 IAP）会 **忽略** LAN Pro；请在该商店购买或恢复 Pro。
- 取消配对即停止证明。

## 信任摘要

| 操作 | 信任含义 |
|--------|-------------------|
| 配对 | 与该对端在局域网共享会话密钥 |
| 保险库克隆 | 对端收到完整保险库副本（密文 + 解锁材料）；需同一主密码才能解锁 |
| 链接保险库 | 共享保险库密钥材料 — 对端可同步完整保险库密文 |
| 发送条目 | 对端收到该条目的密文 |
| LAN Pro | 对端可能在无 IAP 平台解锁 Pro 限额 |

仅与你信任的设备与人员配对、克隆并链接。细节：[安全 → 威胁模型](./security#威胁模型)。
