# 导入与导出

在 OpenKey 与其他密码管理器之间迁移密码，或创建加密的完整保险库备份。路径：**设置 → 数据 → 导入与导出**（以及用于 `.okbak` 的 **备份与恢复**）。

| 操作 | 免费 | Pro |
|--------|------|-----|
| 导入（下方所有格式） | 是 | 是 |
| 导出（下方所有格式） | — | 是 |
| 加密本地备份 / 恢复（`.okbak`） | — | 是 |

导出与备份会在设备上解密后再写入文件 — 请将每次导出视为**机密**。优先使用离线加密存储。参见 [常见问题](./faq) 与 [免费与 Pro](./app#免费与-openkey-pro)。

## 导入步骤

1. 解锁 OpenKey。
2. **设置 → 数据 → 导入与导出 → 导入**。
3. 选择格式，选择文件，确认。
4. 在保险库中查看新条目/集合。若使用[服务器](./server)，请同步。

### Bitwarden JSON

1. 在 Bitwarden：导出 **JSON**（未加密导出 — 请保护该文件）。
2. 在 OpenKey：导入 → **Bitwarden JSON**。
3. 文件夹尽可能映射为集合；登录项变为条目。

### Chrome / Edge CSV

1. 浏览器密码管理器 → 导出 CSV。
2. OpenKey → 导入 → **Chrome CSV**。
3. 期望 url / username / password 列；自定义字段可能有限。

### LastPass CSV

1. LastPass → 导出 CSV。
2. OpenKey → 导入 → **LastPass CSV**。

### 1Password CSV

1. 1Password → 导出 CSV（OpenKey 导入器支持的格式）。
2. OpenKey → 导入 → **1Password CSV**。
3. 复杂条目类型可能扁平化为类似登录的条目。

### KeePass（`.kdbx`）

1. OpenKey → 导入 → **KeePass `.kdbx`**。
2. 输入数据库密码及可选的**密钥文件**。
3. 组变为集合；字段映射清晰时条目作为登录导入。

密码 / 密钥文件错误 → 解锁失败；无服务器往返（全部本地）。

### OpenKey JSON

OpenKey 原生导出的往返格式。用于在无服务器同步时在设备间迁移，或作为可移植的保险库转储（创建文件需要 **Pro**）。

**附件：** OpenKey JSON 导出包含条目上的附件*元数据*，但**省略附件密文 blob**。若需要包含附件的完整保险库，请改用加密的 **`.okbak`** 备份。

## 导出步骤（Pro）

1. **设置 → 数据 → 导入与导出 → 导出**。
2. 选择格式。对于 KeePass，设置新的数据库密码（及可选密钥文件）。
3. 将文件保存到加密 / 离线位置。
4. 迁移完成后删除明文导出。

可用导出：**OpenKey JSON**、**Bitwarden JSON**、**Chrome CSV**、**LastPass CSV**、**KeePass `.kdbx`**、**1Password CSV**。

## 加密备份（Pro）

**设置 → 数据 → 备份与恢复**

- 创建完整保险库 `.okbak`（数据库、设置、附件），使用您的保险库凭据加密以便恢复。
- 恢复会替换本地保险库数据 — 继续前请确认。
- Nearby / 服务器同步**不是**备份（[常见问题](./faq)）。

## 从其他管理器迁移之后

1. 抽查重要登录（以及您使用过的 TOTP）。
2. 启用[自动填充](./app) / [扩展](./extension)。
3. 同步到服务器或配对 Nearby（Pro）以用于其他设备。
4. 安全擦除旧导出文件。
5. 可选：更改在传输期间存在于未加密 CSV 中的密码。
