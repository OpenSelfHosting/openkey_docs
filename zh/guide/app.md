# 使用应用

OpenKey 是适用于 Android、iOS、macOS、Linux 和 Windows 的移动与桌面客户端。核心保险库功能免费；OpenKey Pro 解锁额外功能。您的保险库在设备上加密存储；自托管 [服务器](./server) 用于同步（可选）。请从您平台的官方商店或下载渠道安装。

## 安装

1. 从您平台的官方商店 / 分发渠道获取 OpenKey（见 [下载](./download)）。
2. 打开应用，使用主密码创建或解锁保险库。

本项目相关软件包包括 [服务器](./server)、[浏览器扩展](./extension) 和 [CLI](./cli)。



## 免费与 OpenKey Pro {#free-vs-openkey-pro}

核心保险库功能可离线免费使用。在 Android、iOS、macOS、Windows 和 Linux 上，Pro 提高限额并解锁额外功能。在**没有**商店 IAP 的平台（通常是 Windows/Linux）上，已配对的 Nearby 对等方可共享 **LAN Pro** 证明——仅作便利，不是购买的密码学证明（有商店 IAP 的平台会忽略 LAN Pro）。

| | 免费 | Pro |
|--|------|-----|
| 登录条目 | 最多 **50** | 不限 |
| 集合（文件夹） | 最多 **3** | 不限 |
| 支付卡 / 加密钱包 / 开发者密钥 | 各最多 **3** | 不限 |
| 自托管服务器同步、自动填充、导入 | 是 | 是 |
| **导出**、**`.okbak` 备份**、**Nearby**、**组织/共享**、**附件**、**自定义图标** | — | 是 |

在支持商店计费处通过 **设置 → OpenKey Pro** 管理订阅。

## Nearby 局域网保险库同步（Pro）

在同一本地 Wi‑Fi 上、无需服务器同步同一保险库：

1. 在两台设备上解锁 OpenKey，打开 **设置 → 附近设备**。
2. 两边启动 Nearby，用短码配对，然后点 **链接保险库**。
3. 设备须共享同一保险库密钥（相同指纹）。若不同，接收方可在确认主密码后采用对等方密钥（会替换本地保险库数据）。
4. 链接后，双方解锁并广播时自动同步；可用 **立即同步** 手动追赶。
5. **在本地网络可见** 会被记住：启用一次后，下次解锁保险库会自动恢复 Nearby（锁定时暂停）。
6. 可选 **仅受信任网络**：添加家庭/办公室 Wi‑Fi SSID；未知网络上 Nearby 暂停，回到已知网络后恢复。
7. **受信任设备**：配对并链接保险库一次后，只要 Nearby 开启即可自动重连同步。

局域网同步只传输**密文**（与服务器相同的按 revision 的 LWW）。它不是备份——请另做加密本地备份。详见 [FAQ](./faq) · [共享与组织](./sharing) · [导入与导出](./import-export)。

## 创建或解锁保险库

1. 选择强 **主密码**（建议 12+ 字符且类型混合）。
2. 确认保险库提示：忘记主密码 **无法恢复**；数据在设备上加密；备份很重要。
3. 每次打开应用时用主密码解锁。

主密码绝不会以明文离开设备。

## 日常使用

### 保险库首页

- 浏览 **集合**（文件夹）和密码 **条目**。
- 搜索、按标签筛选，打开条目复制用户名/密码或查看自定义字段。
- 创建带 URL、备注、图标和 TOTP 的条目（如支持）。

### 密码生成器

打开 **设置 → 密码生成器**（或条目表单中的生成器），按您的长度和字符规则生成强密码。

### 卡片、加密资产与密钥

保险库保留区域包含：

- **支付卡**
- **加密钱包**
- **开发者密钥**（API 令牌、SSH 密钥、`.env` 片段）— 亦被 [CLI](./cli) 使用

### 组织与共享

与同一服务器上的其他 OpenKey 用户共享集合或单个条目（**Pro**）。步骤见 [共享与组织](./sharing)。

## 设置概览

| 区域 | 功能 |
|------|----------------|
| **外观** | 主题模式和语言（与本文档站点相同的语言） |
| **安全** | 锁定 / 生物识别 / **系统自动填充**（不是单独页面） |
| **密码生成器** | 默认生成选项 |
| **数据** | 服务器同步、Nearby LAN（Pro）、导入/导出、备份、浏览器扩展、共享 |
| **OpenKey Pro** | 订阅管理（如可用） |

## 连接自托管服务器

1. 运行 [OpenKey Server](./server)。
2. **设置 → 数据 → 自托管服务器** → 设置 URL → **注册** 或 **登录** → **立即同步**。

详情：[安装服务器](./server)。

## 自动填充与浏览器

- **移动 / 桌面 Autofill：** 在 设置 → 安全 中将 OpenKey 设为系统密码与 passkey 提供方。
- **浏览器：** 安装扩展；在桌面上解锁应用并注册原生主机，或在独立模式下针对服务器解锁扩展。

## 导入、导出与备份

完整步骤：[导入与导出](./import-export)。

- **导入 / 导出：** 迁入或迁出密码（Bitwarden JSON、Chrome CSV、1Password CSV、OpenKey JSON）。导出在设备上解密 — 请将文件视为敏感数据。
- **本地备份 / 恢复：** 加密的设备备份（部分功能需 Pro）。
- 即使使用服务器同步，也建议保留离线备份 — 忘记的主密码无法从服务器恢复。

## 良好习惯

- 使用唯一、强主密码。
- 使用服务器时在重大变更后同步。
- 至少保留一份离线备份。
- 离开共享电脑时锁定保险库。
