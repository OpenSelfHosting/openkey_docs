# 无需服务器的 Nearby

自托管同步 API 很强大 — 也是可选的。**Nearby**（OpenKey Pro）在本地网络上保持相同的零知识姿态：设备配对，你显式 **链接保险库**，此后才会移动保险库密钥材料以便对等方同步 **密文**。仅配对不会自动共享保险库密钥。

## 何时使用

- 两台及以上设备在同一家庭或办公室 Wi‑Fi 上
- 你想同步但尚未搭建 Docker / Postgres
- 你需要一次性的 **发送到设备**，推送单个登录项而无需完整保险库拉取

它 **不是** 备份。请离线保留 Pro [加密 `.okbak`](/zh/guide/import-export)。访客网络与客户端隔离会破坏发现 — 请使用常规局域网网段。

## 用二维码配对（推荐）

1. 在两台设备上解锁 OpenKey → **设置 → 附近设备**。
2. 启用 **在本地网络可见**。
3. 在一台设备上显示配对二维码；在另一台 **扫描配对二维码**（或在 Linux/Windows 桌面上 **粘贴配对二维码**）。
4. 点 **链接保险库**，使双方共享同一保险库密钥指纹。

在约两分钟内输入短码仍可用。若 Mac 防火墙在扫描后阻止入站 TCP，OpenKey 可让二维码主机回拨 — 请允许系统网络提示。

## 链接之后

双方在保险库解锁且 Nearby 在广播时，变更会同步（**按 revision 的最后写入获胜**，与服务器相同规则）。受信任设备会自动重连；可选 **仅受信任网络** 会在离开你的 SSID 时暂停 Nearby。**取消配对** 会撤销局域网信任与 LAN Pro 声明。

## LAN Pro，简述

在 Windows / Linux（无商店 IAP）上，**已链接保险库** 的 Pro 对等方可共享 **LAN Pro** 证明，使另一台设备解锁 Pro 限额。仅配对与链接不够。Android、iOS 和 macOS 会忽略它 — 请在商店购买或恢复 Pro。将证明视为便利，而非购买的密码学证明。
