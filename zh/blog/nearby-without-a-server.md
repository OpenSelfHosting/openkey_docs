# 无需服务器的 Nearby

自托管同步 API 很强大 — 也是可选的。**Nearby**（OpenKey Pro）在本地网络上保持相同的零知识姿态：设备相互发现、配对获得会话密钥，然后你要么在设置时 **复制保险库** 到新设备，要么显式 **链接保险库** 以进行持续合并同步。仅配对不会自动共享保险库密钥。

## 何时使用

- 两台及以上设备在同一家庭或办公室 Wi‑Fi 上
- 你想同步但尚未搭建 Docker / Postgres
- **新手机或桌面** 应在无需 `.okbak` 文件的情况下收到完整保险库副本
- 你需要一次性的 **发送到设备**，推送单个登录项而无需完整保险库拉取

合并同步 **不是** 备份。请离线保留 Pro [加密 `.okbak`](/zh/guide/import-export)。访客网络与客户端隔离会破坏发现 — 请使用常规局域网网段。

## 将保险库复制到新设备

1. 解锁已有设备 → **设置 → 附近设备** → **在本地网络可见**。
2. 在新设备上，于首次运行设置选择器中选择 **附近设备**。
3. 点按对端 → 确认 → 用 **相同主密码** 解锁。

这会传输经会话加密的完整保险库归档（含附件）。详情：[Nearby → 设置时复制保险库](/zh/guide/nearby#设置时复制保险库保险库克隆)。

## 配对以持续同步

1. 在两台设备上解锁 OpenKey → **设置 → 附近设备**。
2. 启用 **在本地网络可见**。
3. 点按发现的对端进行配对（发现不顺时，约两分钟内输入短码仍可用）。
4. 点 **链接保险库**，使双方共享同一保险库密钥指纹。

若 Mac 防火墙阻止入站 TCP，OpenKey 可让广播主机回拨 — 请允许系统网络提示。

## 链接之后

双方在保险库解锁且 Nearby 在广播时，变更会同步（**按 revision 的最后写入获胜**，与服务器相同规则）。受信任设备会自动重连；可选 **仅受信任网络** 会在离开你的 SSID 时暂停 Nearby。**取消配对** 会撤销局域网信任与 LAN Pro 声明。

## LAN Pro，简述

在 Windows / Linux（无商店 IAP）上，**已链接保险库** 的 Pro 对等方可共享 **LAN Pro** 证明，使另一台设备解锁 Pro 限额。仅配对、未链接不够。Android、iOS 和 macOS 会忽略它 — 请在商店购买或恢复 Pro。将证明视为便利，而非购买的密码学证明。
