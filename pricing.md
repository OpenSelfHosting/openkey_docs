# Pricing

**OpenKey** is free for a full encrypted vault with sensible limits. **OpenKey Pro** removes caps and unlocks export, backups, Nearby, sharing, and attachments.

Store prices are set per region in Apple / Google / Microsoft billing and shown in the app at purchase time. This page explains **what you get** and **how to buy** — not a fixed USD table (stores localize currency and tax).

Related: [Using the app](/guide/app#free-vs-openkey-pro) · [OpenKey Pro explained](/blog/openkey-pro) · [Download](/guide/download) · [Terms](/terms)

## Plans

| Plan | Billing | Notes |
|------|---------|--------|
| **Free** | $0 | Core vault + server sync + autofill + import (with item caps) |
| **Monthly** | Subscription | Auto-renew; cancel anytime in the store |
| **Yearly** | Subscription | Auto-renew; usually best recurring value; cancel anytime |
| **Lifetime** | One-time | Permanent Pro unlock for that store account |

Exact amounts appear under **Settings → OpenKey Pro** on Android, iOS, and macOS (and other IAP platforms when listed).

## Free vs Pro {#free-vs-openkey-pro}

| | Free | Pro |
|--|------|-----|
| Login entries | Up to **50** | Unlimited |
| Collections (folders) | Up to **3** | Unlimited |
| Payment cards | Up to **3** | Unlimited |
| Crypto wallets | Up to **3** | Unlimited |
| Developer secrets | Up to **3** | Unlimited |
| Self-hosted server sync | Yes | Yes |
| Autofill / passkeys (system) | Yes | Yes |
| Browser extension bridge | Yes | Yes |
| Import from other managers | Yes | Yes |
| **Export** | — | Yes |
| **Encrypted `.okbak` backup** | — | Yes |
| **Nearby LAN vault sync** | — | Yes |
| **Organizations & sharing** | — | Yes |
| **Attachments** (~20 MB each) | — | Yes |
| **Custom app icon** | — | Yes |

Zero-knowledge stays the same on Free and Pro: the server still only sees ciphertext. Pro unlocks client features and limits — it is not a hosted “cloud vault” from OpenSelfHosting.

## How to subscribe

1. Install OpenKey from a [download channel](/guide/download) that supports in-app purchases (Play Store, App Store, Mac App Store when listed).
2. Unlock your vault → **Settings → OpenKey Pro**.
3. Choose **Monthly**, **Yearly**, or **Lifetime** and complete the store purchase.
4. Use **Restore purchases** / refresh status if you reinstall or switch devices on the same store account.

### Windows & Linux

In-app purchases are available on **Android, iOS, and macOS**. On Windows and Linux:

- Sign in with the **same OpenKey account** after subscribing on a mobile or Mac device when account-linked Pro is supported, **or**
- Use **LAN Pro** from a paired Nearby Pro peer (convenience only — not a store receipt; Android / iOS / macOS ignore LAN Pro)

Details: [Nearby → LAN Pro](/guide/nearby#lan-pro-attestation) · [FAQ](/guide/faq)

## Manage or cancel

- **Apple:** Settings → Apple ID → Subscriptions (or App Store subscriptions)
- **Google Play:** Play Store → Payments & subscriptions
- **Microsoft:** account.microsoft.com / Store subscriptions when applicable

Refunds follow the store’s policies. See [Terms of Service](/terms).

## FAQ

### Is the free tier usable without paying?

Yes — vault, autofill, import, and self-hosted sync work within the caps above.

### Do I need Pro for a self-hosted server?

No. Server sync is available on Free. Pro adds export, backups, Nearby, orgs/sharing, attachments, and higher limits.

### Will prices change?

Stores may change regional prices. The in-app paywall always shows the current offer for your account and region.
