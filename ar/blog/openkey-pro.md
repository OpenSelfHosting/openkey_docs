# OpenKey Pro — ماذا يُفتح (وماذا لا)

خزنة OpenKey الأساسية تعمل دون اتصال ودون اشتراك. يرفع **Pro** الحدود ويفتح إضافات مهمة عند المزامنة عبر الأجهزة أو التصدير أو المشاركة مع فريق. هذا التقسيم العملي — وتحذير LAN Pro الذي كثيراً ما يربك.

## ما يبقى مجانياً

- خزنة محلية مشفّرة (بحدود المستوى المجاني — أدناه)
- [مزامنة الخادم](/ar/guide/server) المستضاف ذاتياً (نص مشفّر فقط)
- Autofill النظام / مفاتيح المرور حيث يسمح نظام التشغيل
- جسر [امتداد المتصفح](/ar/guide/extension) لتطبيق سطح المكتب المفتوح
- **الاستيراد** من Bitwarden وCSV المتصفح وKeePass وغيرها

حدود المستوى المجاني (بنى الجوال/سطح المكتب التي تفرض Pro): **50** إدخال تسجيل دخول؛ **3** مجموعات وبطاقات دفع ومحافظ عملات وأسرار مطوّر لكل منها.

## ما يفتحه Pro

| القدرة | ملاحظات |
|------------|--------|
| إدخالات / مجموعات / بطاقات / عملات / أسرار بلا حد | يزيل حدود المجاني |
| **التصدير** + نسخ **`.okbak`** مشفّر | عامل التصدير كمادة سرية |
| مزامنة **Nearby** على LAN | اقتران QR، ربط الخزنة، إرسال إدخال — [الدليل](/ar/guide/nearby) |
| المنظمات والمشاركة | نفس الخادم المستضاف ذاتياً |
| مرفقات على الإدخالات | نحو 20 MB لكل منها، ciphertext على الخادم |
| أيقونة تطبيق مخصّصة | حيث تدعم المنصة |

المصفوفة الكاملة: [التسعير](/ar/pricing) · [استخدام التطبيق ← المجاني مقابل Pro](/ar/guide/app).

## LAN Pro ليست إيصال متجر

على المنصات **بلا** شراء داخل التطبيق من المتجر (غالباً Windows / Linux)، يمكن لنظير Pro مشاركة شهادة **LAN Pro** عبر Nearby.

- تسهيل فقط — **ليست** إثبات شراء مشفّر
- Android و iOS و macOS **تتجاهل** LAN Pro؛ اشترِ أو استعد Pro من ذلك المتجر
- إلغاء الاقتران يوقف الشهادة
