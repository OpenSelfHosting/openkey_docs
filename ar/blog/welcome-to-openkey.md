# مرحباً بـ OpenKey

معظم مديري كلمات المرور يطلبون منك الوثوق بسحابة لا تتحكم بها. OpenKey يسلك الطريق الآخر: تبقى خزنتك مشفّرة على الجهاز، وخادم المزامنة الاختياري يخزّن **نصاً مشفّراً فقط**، وكلمات المرور الرئيسية لا تغادر العميل أبداً.

## نص مشفّر فقط

يشفّر العملاء بيانات الخزنة قبل أن تغادر الجهاز. واجهة المزامنة — إن استخدمتها — تخزّن كتلًا غير شفافة. أسماء المجموعات وحمولات العناصر والمرفقات وأسماء المنظمات وبيانات المشاركة تبقى نصاً مشفّراً أثناء التخزين. اختراق قاعدة البيانات يعطي ملحاً ومعاملات KDF ومفاتيح ملفوفة وكتلًا — لا تسجيلات دخول قابلة للقراءة.

## ما يتوفر اليوم

| المكوّن | الدور |
|---------|------|
| **التطبيق** | خزنة يومية على Android و iOS و macOS و Linux و Windows — تسجيلات دخول، بطاقات، محافظ عملات، أسرار مطوّرين، منظمات ومشاركة |
| **الخادم** | واجهة مزامنة zero-knowledge بـ FastAPI و PostgreSQL تستضيفها بنفسك |
| **الإضافة** | تعبئة تلقائية و Passkeys لمتصفحي Chrome و Firefox (MV3) |
| **CLI** | توليد كلمات مرور دون اتصال، اكتشاف أسرار محلية، ومزامنة اختيارية |

يمكنك أيضاً مزامنة الخزنة بين أجهزتك على شبكة Wi‑Fi نفسها عبر **Nearby** (Pro) — دون الحاجة إلى خادم لهذا المسار على الشبكة المحلية. مزامنة الخادم و Nearby تنقلان نصاً مشفّراً فقط (آخر كتابة تفوز حسب `revision`).
