# الاستيراد والتصدير

انقل كلمات المرور بين OpenKey ومديري كلمات مرور آخرين، أو خذ نسخة احتياطية مشفّرة كاملة للخزنة. المسار: **الإعدادات ← البيانات ← استيراد وتصدير** (و**النسخ الاحتياطي والاستعادة** لـ `.okbak`).

| الإجراء | مجاني | Pro |
|--------|------|-----|
| الاستيراد (كل الصيغ أدناه) | نعم | نعم |
| التصدير (كل الصيغ أدناه) | — | نعم |
| نسخ احتياطي / استعادة محلية مشفّرة (`.okbak`) | — | نعم |

التصدير والنسخ الاحتياطي يفكّان التشفير على الجهاز قبل كتابة الملف — عامل كل تصدير كـ **سر**. فضّل تخزيناً مشفّراً دون اتصال. انظر [الأسئلة الشائعة](./faq) و[المجاني مقابل Pro](./app#المجاني-مقابل-openkey-pro).

## مسار الاستيراد

1. افتح قفل OpenKey.
2. **الإعدادات ← البيانات ← استيراد وتصدير ← استيراد**.
3. اختر الصيغة، اختر الملف، أكّد.
4. راجع الإدخالات/المجموعات الجديدة في الخزنة. زامن إلى [خادمك](./server) إن استخدمته.

### Bitwarden JSON

1. في Bitwarden: صدّر **JSON** (تصدير غير مشفّر — احمِ الملف).
2. في OpenKey: استيراد ← **Bitwarden JSON**.
3. المجلدات تُربط بالمجموعات حيث أمكن؛ تسجيلات الدخول تصبح إدخالات.

### Chrome / Edge CSV

1. مدير كلمات مرور المتصفح ← تصدير CSV.
2. OpenKey ← استيراد ← **Chrome CSV**.
3. توقّع أعمدة url / username / password؛ الحقول المخصّصة قد تكون محدودة.

### LastPass CSV

1. LastPass ← تصدير CSV.
2. OpenKey ← استيراد ← **LastPass CSV**.

### 1Password CSV

1. 1Password ← تصدير CSV (الصيغة التي يدعمها مستورد OpenKey).
2. OpenKey ← استيراد ← **1Password CSV**.
3. أنواع العناصر المعقّدة قد تُسطَّح إلى إدخالات شبيهة بتسجيل الدخول.

### KeePass (`.kdbx`)

1. OpenKey ← استيراد ← **KeePass `.kdbx`**.
2. أدخل كلمة مرور قاعدة البيانات و**ملف مفتاح** اختياري.
3. المجموعات تصبح collections؛ الإدخالات تُستورد كتسجيلات دخول عندما تتطابق الحقول.

كلمة مرور / ملف مفتاح خاطئ ← فشل الفتح؛ بلا طلب للخادم (كل شيء محلي).

### OpenKey JSON

صيغة ذهاب وإياب لتصدير OpenKey الأصلي. استخدمها عند النقل بين الأجهزة دون مزامنة خادم، أو كتفريغ محمول للخزنة (**Pro** لإنشاء الملف).

**المرفقات:** تصدير OpenKey JSON يتضمن *بيانات وصفية* للمرفقات على العناصر لكنه **لا يتضمن كتل التشفير (blobs) للمرفقات**. لنسخة كاملة تشمل المرفقات استخدم النسخ الاحتياطي المشفّر **`.okbak`**.

## مسار التصدير (Pro)

1. **الإعدادات ← البيانات ← استيراد وتصدير ← تصدير**.
2. اختر الصيغة. لـ KeePass عيّن كلمة مرور قاعدة جديدة (وملف مفتاح اختياري).
3. احفظ الملف في مكان مشفّر / دون اتصال.
4. احذف التصديرات الصريحة بعد انتهاء النقل.

التصديرات المتاحة: **OpenKey JSON**، **Bitwarden JSON**، **Chrome CSV**، **LastPass CSV**، **KeePass `.kdbx`**، **1Password CSV**.

## النسخ الاحتياطي المشفّر (Pro)

**الإعدادات ← البيانات ← النسخ الاحتياطي والاستعادة**

- ينشئ `.okbak` كاملاً للخزنة (قاعدة البيانات، الإعدادات، المرفقات) مشفّراً للاستعادة ببيانات اعتماد خزنتك.
- الاستعادة تستبدل بيانات الخزنة المحلية — أكّد قبل المتابعة.
- Nearby / مزامنة الخادم **ليست** نسخة احتياطية ([الأسئلة الشائعة](./faq)).

## بعد الانتقال من مدير آخر

1. افحص تسجيلات مهمة (و TOTP إن استخدمته).
2. فعّل [الملء التلقائي](./app) / [الامتداد](./extension).
3. زامن إلى خادمك أو اقرن Nearby (Pro) للأجهزة الأخرى.
4. امسح ملفات التصدير القديمة بأمان.
5. اختيارياً غيّر كلمات المرور التي عاشت في CSV غير مشفّر أثناء النقل.
