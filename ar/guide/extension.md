# امتداد المتصفح

امتداد MV3 لـ **Chrome** و **Edge** و **Brave** و **Firefox**. يمكن فتح القفل مقابل [خادمك المستضاف ذاتياً](./server) (وضع مستقل) أو الملء عبر **تطبيق سطح المكتب** المفتوح القفل (الرسائل الأصلية).

<img src="/guide/extension-unlock-modes-ar.svg" alt="وضعان للفتح: مزامنة مستقلة مع الخادم المستضاف ذاتياً، أو جسر تطبيق سطح المكتب عبر الرسائل الأصلية" class="ok-diagram" width="920" height="400" />

اسم المضيف: `com.openselfhosting.openkey`

## ماذا يفعل

1. **خزنة مستقلة** — افتح القفل بالبريد + كلمة المرور الرئيسية؛ زامن النص المشفّر من خادمك
2. **الجسر الأصلي** — عندما يكون تطبيق OpenKey لسطح المكتب مفتوح القفل، املأ واحفظ عبر الرسائل الأصلية
3. **الملء التلقائي** — طبقات فوق الصفحة، قائمة السياق، واختصار لوحة المفاتيح لتسجيلات الدخول وبطاقات الدفع
4. **حفظ / تحديث** — التقاط تسجيلات دخول جديدة من الصفحة إلى الخزنة
5. **مفاتيح المرور (Passkeys)** — اعتراض WebAuthn `create` / `get`؛ تخزين اعتمادات ES256 (الامتداد مفتوح القفل)
6. **البطاقات والعملات والأسرار** — تصفّح وملء/نسخ مناطق الخزنة المحجوزة
7. **المرفقات** — سرد وتنزيل مرفقات مفكوكة لتسجيل دخول (الوضع المستقل)
8. **المشاركات والمنظمات** — سرد/قبول/إلغاء المشاركات ودعوات المنظمات (الوضع المستقل)

### اختصار لوحة المفاتيح

| الإجراء | Windows / Linux | macOS |
|--------|-----------------|-------|
| ملء تسجيل الدخول بـ OpenKey | `Ctrl+Shift+L` | `⌘⇧L` |

قد يطلب المتصفح تأكيد الاختصار أو إعادة تعيينه إن استخدمته إضافة أخرى.

## التثبيت (غير معبّأ)

قد لا تكون قوائم المتاجر منشورة بعد. ابنِ وحمّل محلياً:

```bash
cd openkey_extension
npm install
npm run build
```

- **Chrome / Edge / Brave:** `chrome://extensions` ← وضع المطوّر ← **Load unpacked** ← اختر `dist/`
- **Firefox:** `about:debugging` ← This Firefox ← **Load Temporary Add-on** ← اختر `dist/manifest.json`

انسخ معرّف الامتداد من النافذة المنبثقة أو الخيارات — تحتاجه لربط جسر سطح المكتب على متصفحات Chromium.

## الأذونات

يستخدم الامتداد تطابقات المضيف / سكربت المحتوى `<all_urls>` حتى يعمل الملء التلقائي والتقاط تسجيل الدخول واعتراض مفاتيح المرور على المواقع التي تزورها (لا يمكن لقائمة ثابتة تغطية الويب المفتوح). تبقى مزامنة النص المشفّر وفتح القفل على جهازك أو [خادمك المستضاف ذاتياً](./server)؛ OpenKey لا يُرسل HTML الصفحة إلى سحابة بائع. فضّل **استخدام تطبيق سطح المكتب** عندما تريد الملء دون فتح خزنة امتداد منفصلة.

## أوضاع فتح القفل

### خادم مستضاف ذاتياً

1. عيّن **رابط الخادم المستضاف ذاتياً** في النافذة المنبثقة أو الخيارات.
2. **إنشاء حساب** (تسجيل) أو **فتح القفل** (prelogin ثم login بنفس البريد وكلمة المرور الرئيسية للتطبيق).
3. تُزامن النص المشفّر عبر `POST /sync`. كلمة المرور الرئيسية لا تغادر العميل.

### جسر تطبيق سطح المكتب

1. افتح قفل تطبيق OpenKey لسطح المكتب.
2. فعّل الملء التلقائي / اربط الامتداد (خطوات المنصة أدناه).
3. في الامتداد اختر **استخدام تطبيق سطح المكتب**.

الملء والحفظ يمرّان عبر التطبيق المفتوح — بلا فتح قفل منفصل للامتداد لهذه التدفقات.

اختياري: **الإعدادات ← امتداد المتصفح ← نسخ رابط الخزنة دون اتصال** في التطبيق للإقلاع المعزول عن الشبكة.

## ربط الرسائل الأصلية

### Windows

فتح **الإعدادات ← الملء التلقائي** يسجّل `openkey_native_host.exe` تحت:

`HKCU\Software\...\NativeMessagingHosts\com.openselfhosting.openkey`

لـ Chromium، اكتب معرّف الامتداد غير المعبّأ في:

`%LOCALAPPDATA%\OpenKey\chrome_extension_id.txt`

ثم افتح الملء التلقائي مجدداً لإعادة توليد بيان المضيف. Firefox يستخدم `openkey@openselfhosting.local` تلقائياً.

أبقِ الخزنة مفتوحة القفل (TCP محلي).

### macOS

عند فتح القفل، يثبّت OpenKey `openkey_native_host.py` ويكتب البيانات تحت مجلدات NativeMessagingHosts لـ Chrome / Chromium / Edge / Brave / Firefox.

1. حمّل الامتداد غير المعبّأ وانسخ معرّفه.
2. التطبيق: **الإعدادات ← امتداد المتصفح** ← الصق المعرّف ← **ربط الامتداد**.
3. أبقِ الخزنة مفتوحة ← الامتداد: **استخدام تطبيق سطح المكتب**.

يتطلب **Python 3** على `PATH`.

### Linux

**الإعدادات ← الملء التلقائي** يكتب بيانات المضيف تحت `~/.config/google-chrome/` و Chromium و Edge و `~/.mozilla/native-messaging-hosts/`.

ملف معرّف Chromium:

`~/.local/share/OpenKey/chrome_extension_id.txt`

ثم اضغط الملء التلقائي مجدداً. Firefox يستخدم `openkey@openselfhosting.local`.

مقبس الجسر: `$XDG_RUNTIME_DIR/openkey-native.sock` (أبقِ الخزنة مفتوحة).

## حفظ تسجيلات الدخول الملتقطة

بعد إرسال نموذج تسجيل الدخول (أو زر الدخول / Enter)، يعرض شريط داخل الصفحة **حفظ** أو **تحديث**:

1. **الجسر الأصلي** — `createEntry` / `updateEntry` على تطبيق سطح المكتب المفتوح
2. **المستقل** — تشفير محلي ودفع النص المشفّر عبر المزامنة

نفس المضيف + اسم المستخدم + كلمة المرور يُتجاهل؛ تغيّر كلمة المرور يطلب التحديث.

## مفاتيح المرور

مع الامتداد مفتوح القفل، يمكن لـ OpenKey التعامل مع WebAuthn على المواقع. حوار داخل الصفحة للتأكيد؛ اختر **استخدام المتصفح** للرجوع لمصادق المنصة.

اختبار سريع بعد الفتح: [webauthn.io](https://webauthn.io) أو `npx tsx src/passkey/smoke.test.ts` داخل `openkey_extension`.
