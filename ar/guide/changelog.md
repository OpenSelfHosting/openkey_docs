# سجل التغييرات

ملاحظات الإصدار لـ OpenKey. إصدار التطبيق الرسمي هو وسم GitHub على [OpenSelfHosting/OpenKey](https://github.com/OpenSelfHosting/OpenKey/releases) (السورس خاص). الحزم المفتوحة تُصدَّر بشكل مستقل. إصدار التوثيق يتبع هذا الموقع.

## 1.0.6 (2026-08-28)

متوافق مع التطبيق **1.0.6+7**. التفاصيل بالإنجليزية: [Changelog](/guide/changelog#10-06-2026-08-28).

- Linux: AppImage و `.deb` و `.rpm` وأرشيف Arch
- أيقونة بزوايا دائرية على سطح المكتب وموقع التوثيق
- Nearby: دمج الخزنة على LAN، منافذ 47821/47822، إيقاف عند القفل
- الملء التلقائي أغنى على أندرويد/iOS/macOS
- بطاقات إضافية (UnionPay، RuPay، Elo، Hipercard، Mir)
- استعادة `.okbak` من شاشة الإعداد الأولى
- CLI من Termux عبر `OPENKEY_NATIVE_PORT` و `OPENKEY_NATIVE_TOKEN`

## 1.0.2 (2026-08-13)

See [English changelog](/guide/changelog#10-02-2026-08-13) — web target removed; app **1.0.2+3**.

## 1.0.0 (2026)

أول قطع توثيق عام متوافق مع التطبيق **1.0.0+1** والحزم المفتوحة (`openkey_server`، `openkey_extension`، `openkey_cli`، `openkey_docs`).

### التطبيق

- خزنة محلية مشفّرة: مجموعات، تسجيلات دخول، بطاقات، محافظ عملات، أسرار مطوّر، TOTP
- Autofill النظام / Credential Provider ومفاتيح المرور (حسب المنصة)
- مزامنة خادم مستضاف ذاتياً (نص مشفّر فقط)
- مزامنة Nearby على LAN بين أجهزة مقترنة (**Pro**)
- منظمات ودعوات ومشاركات عناصر/مجموعات (**Pro**)
- استيراد (مجاني) / تصدير ونسخ `.okbak` (**Pro**)
- حدود المستوى المجاني: 50 إدخالاً، 3 مجموعات / بطاقات / عملات / أسرار
- تعبئة لـ Play و App Store و Mac App Store و Microsoft Store و Snap و Flathub ومثبّتات سطح المكتب

### الخادم

- واجهة مزامنة FastAPI بلا معرفة + PostgreSQL 16
- مصادقة (`prelogin` / تسجيل / دخول / تحديث / إعادة مفتاح / حذف)، مزامنة، مرفقات، منظمات، مشاركات
- JWT قصيرة العمر، رموز تحديث معتمة دوّارة، حد معدّل للمصادقة، CORS صارم

### امتداد المتصفح

- MV3 لـ Chrome / Firefox: فتح قفل مستقل + مزامنة، أو جسر رسائل أصلية لسطح المكتب
- ملء تلقائي، حفظ/تحديث، مفاتيح مرور، بطاقات / عملات / أسرار، مشاركات ومنظمات (مستقل)

### CLI

- `gen` دون اتصال، جسر أصلي لتطبيق سطح المكتب المفتوح، `discover`، إدارة أسرار
- جلسة خادم اختيارية `login` / `unlock` / `sync`

### موقع التوثيق

- موقع منتج VitePress بـ 10 لغات (RTL للعربية والأردية)
- أدلة: نظرة عامة، أمان، بداية سريعة، تنزيل، خادم (مع reverse proxy لـ HTTPS ونظرة API)، تطبيق، **Nearby**، امتداد، CLI، مشاركة، استيراد/تصدير، أسئلة شائعة، حزم، سجل تغييرات
- **الصينية (zh) والإسبانية (es) والفرنسية (fr)** بمجموعات أدلة كاملة تقريباً مثل EN/AR
- مقالات مدونة (كاملة EN + AR؛ باقي اللغات تشير للإنجليزي) بما فيها **Nearby بلا خادم** و**OpenKey Pro**
- **التسعير** (`/ar/pricing`): مصفوفة المجاني مقابل Pro، شهري / سنوي / مدى الحياة، ملاحظات IAP و LAN Pro
- سياسة الخصوصية والشروط لروابط المتجر / حول التطبيق
- الصفحة الرئيسية: بطل + أقسام الميزات / المنصات / كيف تعمل / دعوة للعمل
- تذييل الموقع + رابط GitHub
