# قیمتیں

مکمل صفحہ: [English](/pricing) · [العربية](/ar/pricing).

| منصوبہ | نوٹ |
|------|------|
| **مفت** | والٹ + سنک + آٹوفل + امپورٹ (حدوں کے ساتھ) |
| **ماہانہ / سالانہ** | سٹور سبسکرپشن؛ کسی بھی وقت منسوخ |
| **زندگی بھر** | ایک بار خریداری |

علاقائی قیمتیں ایپ میں: **Settings → OpenKey Pro**.
