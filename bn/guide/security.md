# নিরাপত্তা

OpenKey এমনভাবে ডিজাইন করা হয়েছে যাতে সার্ভার আপনার ভল্ট পড়তে না পারে।

## কী ডেরিভেশন

<img src="/guide/security-key-derivation.svg" alt="Key derivation: Argon2id turns email and master password into a master key, which yields an auth hash for login and a wrapped vault key for AES-256-GCM ciphertext" class="ok-diagram" width="920" height="400" />

1. `Argon2id(email + master_password, salt)` মাস্টার কী তৈরি করে।
2. মাস্টার কী **auth hash** (লগইনের জন্য সার্ভারে পাঠানো হয়) তৈরি করে এবং **ভল্ট কী** র‍্যাপ করে।
3. ভল্ট কী কালেকশন নাম ও এন্ট্রি পেলোড এনক্রিপ্ট করে (**AES-256-GCM**)।
4. স্থানীয় ডাটাবেস এনক্রিপশন কী ভল্ট কী থেকে আসে।
5. মাস্টার পাসওয়ার্ড ডিভাইস কখনো ছাড়ে না।

## সার্ভার কী রাখে

| রাখে | রাখে না |
|--------|------------|
| `auth_hash` | মাস্টার পাসওয়ার্ড |
| সল্ট ও KDF প্যারামিটার | সাধারণ ভল্ট কী |
| র‍্যাপ করা (এনক্রিপ্টেড) ভল্ট কী | ডিক্রিপ্টেড কালেকশন নাম |
| ডেটা, অ্যাটাচমেন্ট, org, শেয়ারের অস্বচ্ছ সিফারটেক্সট | সাধারণ এন্ট্রি পেলোড |

## টোকেন

- অ্যাক্সেস JWT স্বল্পস্থায়ী।
- রিফ্রেশ টোকেন বিশ্রামে হ্যাশ হয় এবং ব্যবহারে ঘোরে।
- অথ এন্ডপয়েন্ট প্রতি ক্লায়েন্ট IP রেট-লিমিটেড।

## ব্যবহারিক নিয়ম

- শক্তিশালী মাস্টার পাসওয়ার্ড বেছে নিন — এটিই আস্থার মূল।
- সার্ভার `JWT_SECRET` দীর্ঘ ও অনন্য রাখুন; প্লেসহোল্ডার স্টার্টআপে প্রত্যাখ্যাত হয়।
- প্রোডাকশনে HTTPS পছন্দ করুন এবং `CORS_ORIGINS` লক করুন (`*` নয়)।
- ভল্ট এক্সপোর্ট / রিকভারি উপাদানের অফলাইন ব্যাকআপ রাখুন।

API বিস্তারিত জানতে `openkey_server` README এবং চলমান সার্ভারের `/docs` দেখুন।
