# ওভারভিউ

OpenKey একটি **স্ব-হোস্টেড, end-to-end এনক্রিপ্টেড পাসওয়ার্ড ম্যানেজার**। ক্লায়েন্টরা ডেটা ডিভাইস ছাড়ার আগে ভল্ট এনক্রিপ্ট করে। ঐচ্ছিক সিঙ্ক সার্ভার **শুধু ciphertext** সংরক্ষণ করে — মাস্টার পাসওয়ার্ড ও প্লেইনটেক্সট ভল্ট কী কখনো ক্লায়েন্ট ছাড়ে না।

## আপনি যা পাবেন

- স্থানীয় এনক্রিপ্টেড ভল্ট (কালেকশন, লগইন, কার্ড, ক্রিপ্টো ওয়ালেট, ডেভেলপার সিক্রেট)
- আপনার নিজের সার্ভারের মাধ্যমে ডিভাইস জুড়ে ঐচ্ছিক সিঙ্ক
- autofill ও passkeys সহ ব্রাউজার এক্সটেনশন
- মোবাইল / ডেস্কটপ অ্যাপ এবং ওপেন ডেভেলপার CLI
- সংগঠন, শেয়ারড কালেকশন ও আইটেম শেয়ার — সার্ভারে এখনও ciphertext

## Zero-knowledge মডেল

1. ক্লায়েন্ট **Argon2id** দিয়ে মাস্টার পাসওয়ার্ড থেকে কী derive করে।
2. `auth_hash` মাস্টার পাসওয়ার্ড প্রকাশ না করে সার্ভারে authenticate করে।
3. ভল্ট বিষয়বস্তু ভল্ট কী দিয়ে এনক্রিপ্টেড থাকে যা সার্ভার প্লেইনটেক্সটে দেখে না।
4. নাম, পে-লোড, attachment, org নাম ও শেয়ার পে-লোড সার্ভারে opaque ciphertext।

## ওপেন প্যাকেজ

| প্যাকেজ | ভূমিকা |
|---------|------|
| `openkey_server` | FastAPI zero-knowledge সিঙ্ক API + PostgreSQL |
| `openkey_extension` | MV3 ব্রাউজার এক্সটেনশন (Chrome / Firefox) |
| `openkey_cli` | ডেভেলপার CLI (সিক্রেট, পাস জেন, সিঙ্ক) |

মোবাইল ও ডেস্কটপ **OpenKey অ্যাপ** আলাদাভাবে বর্ণিত। পণ্য ব্যবহারের জন্য [অ্যাপ ব্যবহার](./app), সেটআপের জন্য [প্যাকেজ](./packages), সিঙ্ক ইনস্টলের জন্য [সার্ভার সেটআপ](./server), এবং স্থানীয়ভাবে স্ট্যাক চালাতে [Quick start](./quick-start) দেখুন।
