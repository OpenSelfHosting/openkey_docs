# অ্যাপ ব্যবহার

OpenKey হল Android, iOS, macOS, Linux এবং Windows-এর জন্য মোবাইল ও ডেস্কটপ ক্লায়েন্ট। মূল ভল্ট বৈশিষ্ট্য বিনামূল্যে; OpenKey Pro অতিরিক্ত সুবিধা খুলে দেয়। আপনার ভল্ট ডিভাইসে এনক্রিপ্টেড থাকে; সিঙ্কের জন্য স্ব-হোস্টেড [সার্ভার](./server) ঐচ্ছিক। অ্যাপটি আপনার প্ল্যাটফর্মের অফিসিয়াল স্টোর বা ডাউনলোড চ্যানেল থেকে ইনস্টল করুন।

<img src="/app_icon.png" alt="OpenKey app icon" width="96" height="96" style="border-radius: 20px; margin: 1rem 0;" />

## ইনস্টল

1. আপনার প্ল্যাটফর্মের অফিসিয়াল স্টোর / ডিস্ট্রিবিউটর থেকে OpenKey নিন।
2. অ্যাপ খুলুন এবং মাস্টার পাসওয়ার্ড দিয়ে ভল্ট তৈরি বা আনলক করুন।

এই প্রকল্পের ওপেন-সোর্স প্যাকেজ শুধু [সার্ভার](./server), [ব্রাউজার এক্সটেনশন](./extension) এবং [CLI](./cli) কভার করে।



## ফ্রি বনাম OpenKey Pro {#free-vs-openkey-pro}

মূল ভল্ট ফিচার সাবস্ক্রিপশন ছাড়াই অফলাইনে চলে। Android, iOS, macOS, Windows ও Linux-এ Pro সীমা বাড়ায় ও অতিরিক্ত ফিচার খোলে। Web বিল্ড এখনো Pro প্রয়োগ করে না। **স্টোর IAP ছাড়া** প্ল্যাটফর্মে (সাধারণত Windows/Linux) পেয়ার Nearby **LAN Pro** অ্যাটেস্টেশন শেয়ার করতে পারে — শুধু সুবিধা, ক্রয়ের ক্রিপ্টো প্রমাণ নয়।

| | ফ্রি | Pro |
|--|------|-----|
| লগইন এন্ট্রি | সর্বোচ্চ **50** | সীমাহীন |
| কালেকশন (ফোল্ডার) | সর্বোচ্চ **3** | সীমাহীন |
| কার্ড / ক্রিপ্টো / সিক্রেট | প্রতিটিতে সর্বোচ্চ **3** | সীমাহীন |
| সার্ভার সিঙ্ক, অটোফিল, ইমপোর্ট | হ্যাঁ | হ্যাঁ |
| **এক্সপোর্ট**, **`.okbak` ব্যাকআপ**, **Nearby**, **orgs/শেয়ার**, **অ্যাটাচমেন্ট**, **আইকন** | — | হ্যাঁ |

স্টোর বিলিং থাকলে: **সেটিংস → OpenKey Pro**।

## Nearby LAN ভল্ট সিঙ্ক (Pro)

সার্ভার ছাড়াই লোকাল Wi‑Fi-তে একই ভল্ট সিঙ্ক করুন:

1. দুই ডিভাইসে OpenKey আনলক → **সেটিংস → কাছের ডিভাইস**।
2. দুদিকে Nearby চালু, ছোট কোডে পেয়ার, তারপর **Link vault**।
3. একই vault key (একই fingerprint) লাগবে। আলাদা হলে রিসিভার পিয়ারের key নিতে পারে (মাস্টার পাসওয়ার্ড নিশ্চিতের পর লোকাল ডেটা বদলায়)।
4. লিংকের পর দুই আনলক থাকলে অটো সিঙ্ক; ম্যানুয়ালের জন্য **Sync now**।
5. **লোকাল নেটওয়ার্কে দৃশ্যমান** মনে রাখা হয়: একবার চালু করলে পরের আনলকে Nearby ফিরে আসে।
6. ঐচ্ছিক **শুধু বিশ্বস্ত নেটওয়ার্ক**: SSID যোগ করুন; অজানা নেটওয়ার্কে Nearby থেমে যায়।
7. **বিশ্বস্ত ডিভাইস**: এক পেয়ারিং + লিংকের পর Nearby চালু থাকলে নিজে থেকেই যুক্ত হয়।

LAN সিঙ্ক শুধু **ciphertext** পাঠায় (revision অনুযায়ী LWW)। এটি ব্যাকআপ নয়। দেখুন [FAQ](./faq) · [শেয়ারিং](./sharing) · [ইমপোর্ট/এক্সপোর্ট](./import-export)।

## ভল্ট তৈরি বা আনলক

1. একটি শক্তিশালী **মাস্টার পাসওয়ার্ড** বেছে নিন (১২+ অক্ষর মিশ্র ধরনের সুপারিশ)।
2. ভল্ট নোটিশ স্বীকার করুন: মাস্টার পাসওয়ার্ড ভুলে গেলে **কোনো পুনরুদ্ধার নেই**; ডেটা ডিভাইসে এনক্রিপ্টেড; ব্যাকআপ গুরুত্বপূর্ণ।
3. অ্যাপ খোলার সময় মাস্টার পাসওয়ার্ড দিয়ে আনলক করুন।

মাস্টার পাসওয়ার্ড কখনো প্লেইনটেক্সটে ডিভাইস ছাড়ে না।

## দৈনন্দিন ব্যবহার

### ভল্ট হোম

- **কালেকশন** (ফোল্ডার) এবং পাসওয়ার্ড **এন্ট্রি** ব্রাউজ করুন।
- খুঁজুন, ট্যাগ দিয়ে ফিল্টার করুন, এবং ইউজারনেম/পাসওয়ার্ড কপি বা কাস্টম ফিল্ড দেখতে এন্ট্রি খুলুন।
- URL, নোট, আইকন এবং TOTP সহ এন্ট্রি তৈরি করুন যেখানে সমর্থিত।

### পাসওয়ার্ড জেনারেটর

**Settings → Password generator** (বা এন্ট্রি ফর্ম থেকে জেনারেটর) খুলে আপনার দৈর্ঘ্য ও অক্ষর নিয়মে শক্তিশালী পাসওয়ার্ড তৈরি করুন।

### কার্ড, ক্রিপ্টো ও সিক্রেট

সংরক্ষিত ভল্ট এলাকায়:

- **পেমেন্ট কার্ড**
- **ক্রিপ্টো ওয়ালেট**
- **ডেভেলপার সিক্রেট** (API টোকেন, SSH কী, `.env` স্নিপেট) — [CLI](./cli)-তেও ব্যবহৃত

### সংগঠন ও শেয়ারিং

একই সার্ভারে অন্যান্য OpenKey ব্যবহারকারীর সাথে কালেকশন বা পৃথক আইটেম শেয়ার করুন। org নাম ও শেয়ার পে-লোড সার্ভারে ciphertext হিসেবে থাকে।

## সেটিংস মানচিত্র

| এলাকা | কাজ |
|------|----------------|
| **Appearance** | থিম মোড ও ভাষা (এই ডক্স সাইটের একই লোকেল) |
| **Security** | লক / বায়োমেট্রিক্স / সম্পর্কিত সুরক্ষা |
| **Password generator** | ডিফল্ট জেনারেশন অপশন |
| **Data** | সার্ভার সিঙ্ক, ইমপোর্ট/এক্সপোর্ট, ব্যাকআপ, ব্রাউজার এক্সটেনশন, শেয়ারিং |
| **OpenKey Pro** | উপলব্ধ হলে সাবস্ক্রিপশন ব্যবস্থাপনা |

## স্ব-হোস্টেড সার্ভার সংযোগ

1. [OpenKey Server](./server) চালান।
2. **Settings → Data → Self-hosted server** → URL সেট → **Register** বা **Login** → **Sync now**।

বিস্তারিত: [সার্ভার ইনস্টল](./server)।

## Autofill ও ব্রাউজার

- **মোবাইল / ডেস্কটপ Autofill:** Settings → Security-এ OpenKey-কে সিস্টেম পাসওয়ার্ড ও passkey প্রোভাইডার হিসেবে সক্ষম করুন।
- **ব্রাউজার:** এক্সটেনশন ইনস্টল করুন; ডেস্কটপে অ্যাপ আনলক করে নেটিভ হোস্ট রেজিস্টার করুন, অথবা standalone মোডে সার্ভারের বিপরীতে এক্সটেনশন আনলক করুন।

## ইমপোর্ট, এক্সপোর্ট ও ব্যাকআপ

- **Import / export:** পাসওয়ার্ড ভিতরে/বাইরে স্থানান্তর (Bitwarden JSON, Chrome CSV, 1Password CSV, OpenKey JSON)। এক্সপোর্ট ডিভাইসে ডিক্রিপ্ট — ফাইল সংবেদনশীল হিসেবে রাখুন।
- **Local backup / restore:** এনক্রিপ্টেড ডিভাইস ব্যাকআপ (প্রয়োজনে Pro)।
- সার্ভার সিঙ্ক ব্যবহার করলেও অফলাইন ব্যাকআপ রাখুন — ভুলে যাওয়া মাস্টার পাসওয়ার্ড সার্ভার থেকে পুনরুদ্ধার করা যায় না।

## ভালো অভ্যাস

- অনন্য, শক্তিশালী মাস্টার পাসওয়ার্ড ব্যবহার করুন।
- সার্ভার ব্যবহারে বড় পরিবর্তনের পর সিঙ্ক করুন।
- অন্তত একটি অফলাইন ব্যাকআপ রাখুন।
- শেয়ার্ড মেশিন থেকে সরে গেলে ভল্ট লক করুন।
