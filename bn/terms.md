## 1. সেবা

OpenKey একটি password manager যা vault data আপনার device-এ encrypt করে। Optional sync API **ciphertext only** store করে যখন app আপনার control-এর server (অথবা অন্য কেউ আপনার জন্য operate করে) দেখায়। OpenSelfHosting docs-এ described free core experience-এর অংশ mandatory hosted vault cloud দেয় না।

## 3. আপনার account ও master password

- **Master password**-এ vault create ও control করেন।
- **Master-password recovery নয়।** forget করলে ও unlockable device session বা encrypted backup না থাকলে ciphertext unrecoverable — by design।
- Strong master password বেছে নেওয়া, প্রয়োজনীয় backups রাখা, vault unlocked থাকলে devices secure করার দায়িত্ব আপনার।
