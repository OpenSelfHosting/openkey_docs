OpenKey एक password manager है जो vault data आपके device पर encrypt करता है। Optional sync API **ciphertext only** store करता है जब आप app को server पर point करते हैं जो आप control करते हैं (या जो कोई और आपके लिए operate करता है)। OpenSelfHosting docs में described free core experience का हिस्सा mandatory hosted vault cloud provide नहीं करता।

## 3. आपका account और master password

- आप **master password** से अपना vault create और control करते हैं।
- **Master-password recovery नहीं है।** यदि forget करें और unlockable device session या encrypted backup नहीं है जो open कर सकें, ciphertext unrecoverable है — by design।
- आप strong master password choose करने, जरूरी backups रखने, और vault unlocked होने पर devices secure करने के responsible हैं।
