# ऐप का उपयोग

OpenKey Android, iOS, macOS, Linux और Windows के लिए मोबाइल और डेस्कटॉप क्लाइंट है। मुख्य vault सुविधाएँ मुफ़्त हैं; OpenKey Pro अतिरिक्त सुविधाएँ खोलता है। आपका vault डिवाइस पर एन्क्रिप्टेड रहता है; सिंक के लिए self-hosted [सर्वर](./server) वैकल्पिक है। ऐप अपने प्लेटफ़ॉर्म के आधिकारिक स्टोर या डाउनलोड चैनल से इंस्टॉल करें।

<img src="/app_icon.png" alt="OpenKey app icon" width="96" height="96" style="border-radius: 20px; margin: 1rem 0;" />

## इंस्टॉल

1. अपने प्लेटफ़ॉर्म के आधिकारिक स्टोर / डिस्ट्रिब्यूटर से OpenKey प्राप्त करें।
2. ऐप खोलें और मास्टर पासवर्ड से vault बनाएँ या अनलॉक करें।

इस प्रोजेक्ट के ओपन-सोर्स पैकेज केवल [सर्वर](./server), [ब्राउज़र एक्सटेंशन](./extension) और [CLI](./cli) कवर करते हैं।



## मुफ़्त बनाम OpenKey Pro {#free-vs-openkey-pro}

मुख्य vault सुविधाएँ बिना सब्सक्रिप्शन ऑफ़लाइन चलती हैं। Android, iOS, macOS, Windows और Linux पर Pro सीमाएँ बढ़ाता और अतिरिक्त सुविधाएँ खोलता है। Web बिल्ड अभी Pro लागू नहीं करते। **स्टोर IAP रहित** प्लेटफ़ॉर्म (आमतौर पर Windows/Linux) पर पेयर Nearby **LAN Pro** attestation साझा कर सकता है — सुविधा मात्र, खरीदारी का क्रिप्टो प्रमाण नहीं।

| | मुफ़्त | Pro |
|--|------|-----|
| लॉगिन प्रविष्टियाँ | अधिकतम **50** | असीमित |
| कलेक्शन्स (फ़ोल्डर) | अधिकतम **3** | असीमित |
| कार्ड / क्रिप्टो / सीक्रेट | प्रत्येक अधिकतम **3** | असीमित |
| सर्वर सिंक, ऑटोफ़िल, इंपोर्ट | हाँ | हाँ |
| **एक्सपोर्ट**, **`.okbak` बैकअप**, **Nearby**, **orgs/शेयर**, **अटैचमेंट**, **आइकन** | — | हाँ |

स्टोर बिलिंग जहाँ उपलब्ध हो: **सेटिंग्स → OpenKey Pro**।

## Nearby LAN वॉल्ट सिंक (Pro)

बिना सर्वर के लोकल Wi‑Fi पर एक ही vault सिंक करें:

1. दोनों डिवाइस पर OpenKey अनलॉक करें → **सेटिंग्स → नज़दीकी डिवाइस**।
2. दोनों पर Nearby शुरू करें, छोटे कोड से पेयर करें, फिर **Link vault**।
3. एक ही vault key (एक fingerprint) ज़रूरी। अलग हों तो रिसीवर peer की key अपना सकता है (मास्टर पासवर्ड पुष्टि के बाद लोकल डेटा बदल जाता है)।
4. लिंक के बाद दोनों अनलॉक रहते हुए ऑटो सिंक; मैनुअल के लिए **Sync now**।
5. **लोकल नेटवर्क पर दृश्य** याद रहता है: एक बार चालू करने के बाद अगली अनलॉक पर Nearby फिर शुरू होता है।
6. वैकल्पिक **केवल विश्वसनीय नेटवर्क**: SSID जोड़ें; अज्ञात नेटवर्क पर Nearby रुकता है।
7. **विश्वसनीय डिवाइस**: एक पेयरिंग + लिंक के बाद Nearby चालू होने पर अपने आप जुड़ते हैं।

LAN सिंक केवल **ciphertext** भेजता है (revision के अनुसार LWW)। यह बैकअप नहीं। देखें [FAQ](./faq) · [शेयरिंग](./sharing) · [इंपोर्ट/एक्सपोर्ट](./import-export)।

## Vault बनाना या अनलॉक करना

1. मज़बूत **मास्टर पासवर्ड** चुनें (12+ मिश्रित वर्ण अनुशंसित)।
2. vault नोटिस स्वीकार करें: मास्टर पासवर्ड भूलने पर **कोई पुनर्प्राप्ति नहीं**; डेटा डिवाइस पर एन्क्रिप्टेड; बैकअप महत्वपूर्ण।
3. ऐप खोलने पर मास्टर पासवर्ड से अनलॉक करें।

मास्टर पासवर्ड कभी plaintext में डिवाइस नहीं छोड़ता।

## रोज़मर्रा का उपयोग

### Vault होम

- **कलेक्शन** (फ़ोल्डर) और पासवर्ड **एंट्री** ब्राउज़ करें।
- खोजें, टैग से फ़िल्टर करें, और यूज़रनेम/पासवर्ड कॉपी या कस्टम फ़ील्ड देखने के लिए एंट्री खोलें।
- URL, नोट, आइकन और TOTP के साथ एंट्री बनाएँ जहाँ समर्थित हो।

### पासवर्ड जेनरेटर

**Settings → Password generator** (या एंट्री फ़ॉर्म से जेनरेटर) खोलकर अपनी लंबाई और वर्ण नियमों से मज़बूत पासवर्ड बनाएँ।

### कार्ड, क्रिप्टो और सीक्रेट

आरक्षित vault क्षेत्रों में:

- **भुगतान कार्ड**
- **क्रिप्टो वॉलेट**
- **डेवलपर सीक्रेट** (API टोकन, SSH कुंजी, `.env` स्निपेट) — [CLI](./cli) द्वारा भी उपयोग

### संगठन और शेयरिंग

एक ही सर्वर पर अन्य OpenKey उपयोगकर्ताओं के साथ कलेक्शन या व्यक्तिगत आइटम शेयर करें। org नाम और शेयर payload सर्वर पर ciphertext रहते हैं।

## सेटिंग्स मानचित्र

| क्षेत्र | कार्य |
|------|----------------|
| **Appearance** | थीम मोड और भाषा (इस docs साइट के समान locales) |
| **Security** | लॉक / बायोमेट्रिक्स / संबंधित सुरक्षा |
| **Password generator** | डिफ़ॉल्ट जेनरेशन विकल्प |
| **Data** | सर्वर सिंक, import/export, बैकअप, ब्राउज़र एक्सटेंशन, शेयरिंग |
| **Autofill** | सिस्टम Autofill / Credential Provider (मोबाइल और डेस्कटॉप) और passkeys |
| **OpenKey Pro** | उपलब्ध होने पर सब्सक्रिप्शन प्रबंधन |

## Self-hosted सर्वर कनेक्ट करें

1. [OpenKey Server](./server) चलाएँ।
2. **Settings → Data → Self-hosted server** → URL सेट → **Register** या **Login** → **Sync now**।

विवरण: [सर्वर इंस्टॉल](./server)।

## Autofill और ब्राउज़र

- **मोबाइल / डेस्कटॉप Autofill:** Settings → Autofill में OpenKey को सिस्टम पासवर्ड और passkey प्रोवाइडर सक्षम करें।
- **ब्राउज़र:** एक्सटेंशन इंस्टॉल करें; डेस्कटॉप पर ऐप अनलॉक कर native host रजिस्टर करें, या standalone मोड में सर्वर के विरुद्ध एक्सटेंशन अनलॉक करें।

## Import, export और बैकअप

- **Import / export:** पासवर्ड अंदर/बाहर ले जाएँ (Bitwarden JSON, Chrome CSV, 1Password CSV, OpenKey JSON)। export डिवाइस पर decrypt — फ़ाइल को संवेदनशील मानें।
- **Local backup / restore:** एन्क्रिप्टेड डिवाइस बैकअप (जहाँ आवश्यक Pro)।
- सर्वर सिंक के बावजूद offline बैकअप रखें — भूला मास्टर पासवर्ड सर्वर से पुनर्प्राप्त नहीं हो सकता।

## अच्छी आदतें

- अद्वितीय, मज़बूत मास्टर पासवर्ड उपयोग करें।
- सर्वर उपयोग में बड़े बदलाव के बाद सिंक करें।
- कम से कम एक offline बैकअप रखें।
- साझा मशीन से हटते समय vault लॉक करें।
